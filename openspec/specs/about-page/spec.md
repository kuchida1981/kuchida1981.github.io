# about-page Specification

## Purpose
フリーランスエンジニアとしての自己紹介ページ（経歴・技術スタック・実績の骨組み）とメニュー導線を提供する。

## Requirements
### Requirement: 自己紹介ページの提供
サイトは `/about/` にフリーランスエンジニアとしての自己紹介ページを提供しなければならない（SHALL）。ページは経歴・得意技術スタック・実績の各セクションを含み、既存の `content/services.md` と同じ `layout: page` を用いた静的 Markdown ページとして実装しなければならない（SHALL）。

#### Scenario: 自己紹介ページへのアクセス
- **WHEN** ユーザーが `/about/` にアクセスする
- **THEN** 経歴・得意技術スタック・実績の各セクションを含む自己紹介ページが表示される

#### Scenario: ページ本文の構成
- **WHEN** `/about/` のページが表示される
- **THEN** タイトル・肩書き、経歴（一段落の文章）、得意技術スタック（箇条書き）、実績・関わってきた領域（箇条書き）の各セクションがこの順で含まれる

### Requirement: メニューからの導線
サイトのメインメニューは `Services` と `Posts` に加えて `About` エントリを含み、`/about/` へリンクしなければならない（SHALL）。

#### Scenario: メインメニューに About が表示される
- **WHEN** サイトの任意のページでメインメニューが表示される
- **THEN** `About` というラベルのメニュー項目が表示され、`/about/` へのリンクになっている

#### Scenario: 既存メニュー項目への影響がないこと
- **WHEN** `About` メニュー項目が追加される
- **THEN** 既存の `Services` および `Posts` メニュー項目のラベル・リンク先は変更されない
