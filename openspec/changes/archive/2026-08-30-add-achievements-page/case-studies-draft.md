## 気象データ配信基盤の新規構築・運用

### 課題
社内の複数プロジェクトがそれぞれ個別に気象情報を扱っており、気象庁の仕様変更のたびに各所で重複した追随対応が発生していた。これを一元化するとともに、社外への外販も見据えた新規サービスとして立ち上げる必要があった。

### 対応
サービスイン前の段階からインフラ設計・アーキテクチャ設計・実装・保守運用までを一貫して担当。大手ニュース配信・データ企業にて週4日のペースで参画し、スクラム開発体制(PO1名・スクラムマスター1名・エンジニア3名)の中で、Go/Echo によるバックエンド開発と Cloud Run・Terraform を用いたインフラ構築を中心に対応した。

### 成果
社内の複数プロジェクトが個別に行っていた気象庁仕様変更対応を一元化。データを社外にも提供する新規事業として立ち上げ、外販は10社未満ながら、販売数だけでなく社内の運用効率化という当初目的も達成した。現在も継続稼働中。

## BtoB向けクラウドサービスの新規開発・保守運用

### 課題
エンドクライアントの既存主力サービスの姉妹プロダクトとして、新規のBtoB向けクラウドサービスを立ち上げる必要があった。

### 対応
受託開発企業経由でリーダーとして参画し、技術スタックの選定から設計・実装・テストまでを担当。Python(Flask)による REST API 開発を中心に、AWS Elastic Beanstalk 上でのインフラ構築、MySQL(RDB)、Amazon CloudSearch などを用いたバックエンド開発を行い、フロントエンド開発メンバーとの連携も担った。

### 成果
技術選定から新規開発、その後の保守・運用まで一貫してリーダーとして担当し、約2年間にわたりサービスを支え続けた。
