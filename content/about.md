## フリーランスエンジニア

2015年よりフリーランスエンジニアとして活動しています。SIer にて Web システムの開発・運用に数年間従事したのち独立し、以降は業務委託を中心に、Web アプリケーションの設計・開発・保守に携わっています。バックエンドからインフラまで一貫して対応できることを強みとし、小〜中規模のチームに参画して開発を推進するスタイルを得意としています。

### 得意技術スタック

* 言語

    * Go, PHP, Python, TypeScript

* フレームワーク / ライブラリ

    * Echo, Laravel, FastAPI, React, Next.js

* インフラ / ミドルウェア

    * AWS (ECS, Lambda, RDS, S3), Docker, Terraform, GitHub Actions

* データストア

    * PostgreSQL, MySQL, Redis

### 実績・関わってきた領域

* BtoB SaaS のバックエンド設計・開発・運用

* EC サイトのリプレイス・パフォーマンス改善

* 社内業務システムの新規構築とレガシーマイグレーション

* REST API / GraphQL API の設計と実装

* CI/CD パイプラインの構築・改善

* クラウドインフラの設計・構築・コスト最適化
